# Release Notes

Release notes for each PIDL version.

## Releases

| Version | Date | Highlights |
|---------|------|------------|
| [v0.9.0](v0.9.0.md) | 2026-10-22 | Embeddable viewer on a CDN, the walkthrough format with schemas, code samples and cURL with sample sets, Postman collections with a signing proxy, narration, and a worked OAuth 2.0 example |
| [v0.8.0](v0.8.0.md) | 2026-10-19 | Walkthrough viewer: a self-contained HTML page per protocol with step highlighting, narratives, requests, responses and decoded tokens; flow examples; fully worked AAuth examples |

| [v0.5.0](v0.5.0.md) | 2026-07-12 | Data lineage, parallel execution, cost tracking, workflow exports, integrations |
| [v0.4.0](v0.4.0.md) | 2026-06-28 | Protocol composition, execution engine, diff, debugger, security analysis |
| [v0.3.0](v0.3.0.md) | 2025-05-18 | SVG rendering, animated flows, templates, network boundary diagrams |
| [v0.2.0](v0.2.0.md) | 2025-04-18 | Annotations, alternatives, conditions, nested phases, D2 renderer |
| [v0.1.0](v0.1.0.md) | 2025-04-18 | Initial release with PlantUML, Mermaid, DOT renderers |
